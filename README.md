# 🍕 Pizza Sales Dashboard

## 📌 Project Overview
This project is a Power BI dashboard created to analyze pizza sales data.

## 📊 Dashboard Features
- Total Sales
- Total Orders
- Total Pizzas Sold
- Monthly Sales Trend
- Category-wise Sales
- Best Selling Pizzas
- Revenue Analysis

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
